# Minecrawl Combat Overhaul

This mod completely overhauls combat and adjacent mechanics.

## Changes to vanilla entity attributes

The base values of several entity attributes were changed for players:
- "generic.attack_damage" set to 0.0
- "generic.attack_speed" set to 0.0

All relevant items were tweaked, to account for these changes. There should be no consequences in regular gameplay.

## Attack Range Attribute

All weapon items were tweaked to use the "attackrangeattribute:generic.attack_range" entity attribute instead of the "minecraft:player.entity_interaction_range" attribute. There should be no consequences in regular gameplay.

> The main reason this is mentioned here at all, is to avoid potential confusion if this mod is used outside the Minecrawl mod pack.
